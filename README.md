# Bilibili 工具箱

一个可配置、可扩展的哔哩哔哩网页增强浏览器扩展。

当前版本提供“视频模块顶部驻留”：在视频详情页向下浏览评论时，将标题、UP 主信息和原播放器保持在页面顶部，并可替代 B 站默认的右下角小窗。关闭功能后，网页完全使用 B 站原有行为。

## 当前功能

- 可设置新打开或刷新的视频页面默认进入 B 站原生宽屏模式；设置变化不影响已经打开的页面。
- 各项增强默认关闭，不改变 B 站页面行为。
- 向下滚动后将视频标题、播放数据、UP 主信息卡和完整原生播放器作为一个模块固定在顶部。
- 保留进度条、控制栏、弹幕发送栏、观看人数，以及 UP 主头像、关注、充电和发消息等原生交互。
- 回到播放器原始位置后自动恢复页面布局。
- 可设置播放器目标屏幕占比和顶部间距；横屏宽屏时会自适应主内容栏宽度，避免缩成居中悬浮框。
- 顶部驻留时自动接管 B 站原生小窗，避免出现重复播放器界面。
- 同时支持普通模式与宽屏模式，并在切换模式后重新测量完整播放器尺寸。
- 自动识别并避让可见的 B 站顶部导航栏，不修改导航栏自身布局。
- 工具栏弹窗提供快捷开关，完整设置页为后续功能预留分类。

## 本地安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本仓库根目录。
5. 打开任意 `https://www.bilibili.com/video/*` 视频页。
6. 点击扩展图标开启“视频模块顶部驻留”，然后刷新已打开的视频页。

设置使用 `chrome.storage.sync` 保存；浏览器开启同步时，设置可在同一账户的浏览器间同步。

## 开发与检查

项目没有运行时依赖，也不需要构建。修改源码后，在扩展管理页点击“重新加载”即可。

```bash
npm run check
```

目录结构：

```text
src/
├── background/   安装与设置初始化
├── content/      B 站页面增强逻辑与样式
├── options/      完整设置页
├── popup/        工具栏快捷面板
└── shared/       设置结构与校验
```

## 兼容范围

- Chrome / Edge，Manifest V3。
- 第一阶段只匹配普通 B 站视频详情页 `/video/*`。
- 番剧、课程、直播和播放列表页面暂未纳入适配范围。
