# Bilibili 工具箱

一个可配置、可扩展的哔哩哔哩网页增强浏览器扩展。

当前版本提供“播放器顶部驻留”：在视频详情页向下浏览评论时，将原播放器保持在页面顶部，并可替代 B 站默认的右下角小窗。关闭功能后，网页完全使用 B 站原有行为。

## 当前功能

- 默认关闭，不改变 B 站页面行为。
- 向下滚动后将完整原生播放器固定在顶部，保留进度条、控制栏、弹幕发送栏和观看人数。
- 回到播放器原始位置后自动恢复页面布局。
- 可限制播放器最大屏幕占比，并设置顶部间距。
- 顶部驻留时自动接管 B 站原生小窗，避免出现重复播放器界面。
- 同时支持普通模式与宽屏模式，并在切换模式后重新测量完整播放器尺寸。
- 工具栏弹窗提供快捷开关，完整设置页为后续功能预留分类。

## 本地安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本仓库根目录。
5. 打开任意 `https://www.bilibili.com/video/*` 视频页。
6. 点击扩展图标开启“播放器顶部驻留”，然后刷新已打开的视频页。

设置使用 `chrome.storage.sync` 保存；浏览器开启同步时，设置可在同一账户的浏览器间同步。

## 开发与检查

项目没有运行时依赖，也不需要构建。修改源码后，在扩展管理页点击“重新加载”即可。

```bash
npm run check
```

目录结构：

```text
src/
├── background/   安装与设置初始化
├── content/      B 站页面增强逻辑与样式
├── options/      完整设置页
├── popup/        工具栏快捷面板
└── shared/       设置结构与校验
```

## 兼容范围

- Chrome / Edge，Manifest V3。
- 第一阶段只匹配普通 B 站视频详情页 `/video/*`。
- 番剧、课程、直播和播放列表页面暂未纳入适配范围。
